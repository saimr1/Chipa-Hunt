# 🩴 Chippa Hunter

**Dodge. Shoot. Survive. CHAPPIES INCOMING!**

A chaotic little arena shooter built with **Python + Pygame** at the Haven Hack Club Game Jam.

Survive endless enemy waves, launch flying chappals, grab health potions, and try not to become the next victim of Chippa Sahab.

## 🎮 Features
- Fast-paced top-down arena combat
- Ricocheting flying chappals
- Endless enemies that chase you
- Health potions and three lives
- Screen shake and particle effects
- Local top-10 leaderboard
- Meme-powered death screen 💀

## 🕹️ Controls

| Key | Action |
|---|---|
| `W A S D` | Move |
| Mouse | Aim |
| Left Click | Shoot |
| `ESC / P` | Pause |
